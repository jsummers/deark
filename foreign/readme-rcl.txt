rcl.h is derived from RECOIL (Retro Computer Image Library), by Piotr Fusik,
approximately version 7.0.0.

https://recoil.sourceforge.net/
https://github.com/pfusik/recoil

rcl.h contains a small portion of the code in recoil.c.
recoil.c is generated from recoil.fu.
recoil.fu is written in the Fusion programming language.
See the file LICENSE-rcl for the original terms of use for recoil.fu.
recoil.fu and recoil.c are from the RECOIL source code, and are not included
with Deark.

The code has been modified for use with Deark.
